# Art assets

These images were generated with Higgsfield (GPT Image 2.6) for this game and are embedded into the build by `src/hf_assets.js`:

- `turf.jpg` - tileable grass blended into the 3D field
- `crowd.jpg` - stadium crowd on the 3D stands
- `day.jpg`, `dusk.jpg`, `night.jpg` - sky panoramas for the time of day
- `menu.jpg` - main menu background

No team logos, text or real people are in them. To regenerate `src/hf_assets.js` after changing an image, base64-encode each jpg into `HF_ART`.
